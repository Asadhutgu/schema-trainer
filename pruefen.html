Zur App

Ordner prüfen

Ziehe den Ordner schemata hierher oder wähle ihn aus. Dann wird zusätzlich geprüft, ob jede Datei im Ordner in der Liste eingetragen ist, und Fehler werden mit Zeilennummer angezeigt. Das geht auch mit einer einzelnen Datei.

Was geprüft wird
  • Jede in schemata/liste.js eingetragene Datei ist vorhanden und lässt sich lesen (keine fehlenden Klammern, Kommas oder Anführungszeichen).
  • Jede Datei enthält genau ein Schema mit den Feldern id, norm, titel, gliederung und punkte.
  • Die id ist eindeutig und besteht nur aus Kleinbuchstaben, Ziffern und Bindestrichen.
  • Die Gliederungszeichen sind bekannt (A., I., 1., a), aa)) und reichen für alle Ebenen.
  • Die Ebenen springen nicht: Jeder Punkt geht höchstens eine Ebene tiefer als der vorige.
  • Jede Definition hat Begriff, Text und Fundstelle; kein Begriff kommt im selben Schema doppelt vor.
  • Die Feldnamen sind richtig geschrieben (zum Beispiel „definition“, nicht „definiton“).
  • Hausstil: Absätze ausgeschrieben („Abs. 2“ statt „II“), die Grundrechtecharta heißt „GRCh“.
  • Beim Prüfen eines Ordners zusätzlich: Jede Datei im Ordner ist in liste.js eingetragen.

Dieselbe Prüfung läuft auf GitHub automatisch bei jeder Änderung (Reiter „Actions“).
